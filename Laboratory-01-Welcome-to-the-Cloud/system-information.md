# System Information

## User Information

The current user information was gathered using the following command:

```bash
whoami
```

## Current Working Directory

The current working directory was checked using:

```bash
pwd
```

## Operating System Information

System and operating system information was gathered using:

```bash
uname -a
```

## Current Date and Time

The current date and time were checked using:

```bash
date
```

The KillerCoda Playground provided a cloud-based Linux environment where I was able to execute Linux commands and explore the system through the terminal.
