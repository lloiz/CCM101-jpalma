# Reflection

## My Learning Experience

This laboratory activity introduced me to the basics of using a cloud-based Linux environment. Through KillerCoda, I was able to access a Linux terminal without installing a complete Linux operating system on my computer.

I learned how to navigate directories, create files and folders, and execute basic Linux commands. I also learned how to gather basic system information using terminal commands.

Another important part of this activity was creating a GitHub repository and organizing the required files. This helped me understand the importance of proper documentation and maintaining an organized project structure.

Overall, this laboratory activity helped me gain practical experience with Cloud Computing, Linux, Markdown, and GitHub. The skills I learned will be useful for future laboratory activities and other IT projects.
