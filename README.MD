# Laboratory 01 – Welcome to the Cloud

## Mission Overview

The purpose of this laboratory activity is to introduce the fundamentals of Cloud Computing and provide hands-on experience using a cloud-based Linux environment.

In this activity, I used KillerCoda to access a Linux terminal and perform basic commands. I also learned how to navigate the Linux file system, create directories and files, gather system information, and organize my work using GitHub.

## Objectives

The objectives of this laboratory activity are:

* To access and use a cloud-based Linux environment.
* To navigate the Linux file system.
* To execute basic Linux commands.
* To gather basic system information.
* To create and organize directories and files.
* To create a professional GitHub portfolio.
* To document laboratory activities using Markdown.
* To upload screenshots as evidence of completed tasks.

## Activities Performed

During this laboratory activity, I completed the following tasks:

1. Accessed the KillerCoda cloud-based Linux environment.
2. Opened and used the Linux terminal.
3. Navigated the Linux file system using basic commands.
4. Gathered information about the operating system and system environment.
5. Created directories and Markdown files.
6. Organized the required laboratory file structure.
7. Created a public GitHub repository.
8. Uploaded the required laboratory files and screenshots.
9. Documented the completed activities using Markdown.
